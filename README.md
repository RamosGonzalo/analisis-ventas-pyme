# Análisis de Ventas - Pyme (Proyecto de portfolio)

Proyecto de análisis de datos que simula las ventas de una pyme ficticia, 
con generación de datos en Python y reporte final en Excel con tablas 
dinámicas y control de presupuesto.

## Objetivo

Combinar Python (generación y limpieza de datos) con Excel (tablas 
dinámicas, gráficos y presupuesto) para practicar y demostrar habilidades 
tanto de análisis de datos como de gestión administrativa.

## Tecnologías

- Python (pandas, Faker, openpyxl)
- Excel (tablas dinámicas, gráficos, presupuesto)
